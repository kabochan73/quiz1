# AI採点クイズアプリ 設計ドキュメント

自作の記述式問題を、Claude API がルーブリックに基づいて採点する個人用学習アプリ（ポートフォリオ用）。
**学んだ内容を自分の言葉で説明できるか（記憶の定着度）を確かめる想起練習ツール。**

## コアコンセプト（3行）

- ユーザーが **クイズ（1〜30問の問題セット）** を作り、各問に「問題文 + ルーブリック（=思い出してほしい要点）」を登録する
- 受験者は選択肢ではなく**自由記述**で全問に回答する
- Claude API が **ルーブリックだけを基準に**（最大10問ずつまとめて）**問ごとの部分点 + フィードバック** を返し、クイズ合計点が出る
- 模範解答はユーザーに書かせない（記憶違いの登録で採点が汚染されるのを防ぐ）。必要なら AI が参考解答を生成

## 現在のフェーズ

**v1（1周目）を設計中。** スコープは「標準構成」= 認証 + クイズ/問題CRUD（1〜30問）+ 階層カテゴリ/タグ + クイズ受験の最大10問ずつAI採点 + 受験履歴 + 簡易成績集計。

技術スタック確定: PHP 8.4 / Laravel 12 / Breeze（Bladeスタック）+ Alpine + Tailwind v4 / SQLite（開発）・PostgreSQL（本番）/ queue=database / 公式 `anthropic-ai/sdk` / Pest 3。採点モデルは `claude-sonnet-5`。詳細は [03-tech-stack.md](./03-tech-stack.md)。
